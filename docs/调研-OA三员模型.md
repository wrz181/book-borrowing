# 调研：致远 OA「三员」模型（T1-1 产出）

> 来源：WorkBuddy 调研子代理（2026-10-19），供 sso_scope 子项 (b)「OA 三员切换」规划使用。
> 证据标注：seeyon-dev 知识库 / 官方 Web 文档 / E:\zhiyuan 本机产品（旁证，非官方文档）。

## 1. 官方角色命名与职责边界
官方叫法为「三员分离/三权分立」，以「三员代替传统的超级管理员，三员之间权限互相制约」。不同产品线命名略异：
- **A8/A8-N 涉密三员分离方案（协同云官方）**：系统管理员、安全保密管理员、审计管理员。
  - 系统管理员：人员及编外人员管理、协同模板及文单设置（人员密级字段仅安全保密管理员可修改）。
  - 安全保密管理员：安全策略配置、密级管理（单位涉密等级设定、全部人员密级设置/变更），起主动安全防御作用。
  - 审计管理员：监督检查与审计跟踪，管理系统管理员登录日志/应用日志/密级日志，并查看系统管理员、单位管理员、安全保密管理员的日志（保密员应用日志单独展示在密级日志审计页）。
- **COP-V8 协同云权限管理文档**：三员账户为「组织管理员、安全保密管理员、审计管理员」，租户内仅一个安全审计管理员，支持授权多人。
- **政务版案例（二十二所）**：系统管理员、安全管理员、安全审计员——与等保「三员」术语对应。

## 2. 「三员切换」形态
官方文档均表述为**「系统提供三员账户」**——即三个独立账户/身份，各自登录各自后台，且互斥规则明确「同一个用户不允许同时担任三员中的两员」。**未查到**「登录时选择身份」或「同一账号切换身份」形态的任何官方描述；「三员切换」一词在官方文档中未出现，推测为项目侧需求用语（实际含义应为：三个三员账号分别登录对应管理后台）。此项标不确定。

## 3. 是否强制三权分立、与普通账号关系
- **非默认强制**：V8 文档中三员分离位于「用户中心-安全管理-分级保护」，需显式「开启三员分离功能」；属面向涉密/等保场景的可选安全特性（国资体系 A8+A8-N 方案）。
- 开启后**三员互斥**：同一用户不得兼任三员中的两员。
- 普通业务账号不属于三员；审计体系明确区分「普通用户」日志与三员日志。普通账号能否兼任某一员，文档未明说（仅明确三员之间互斥）。
- 对照：A6 老版默认仅一个 system 系统管理员账号。

## 4. 覆盖模块（V8 权限矩阵为准）
- 用户管理：内部/外部/特殊用户管理（仅组织管理员）
- 角色管理、授权管理：角色授权、机构管理员授权、审批列表（审批列表保密员也可见）
- 安全管理：三员分离、登录设备管理、账户锁定管理、用户在线管理、水印设置、安全保密管理员配置、安全审计管理员配置、认证服务
- 日志管理：登录/操作/授权/越权日志（三员均可看）
- 权限审计：资源审计、用户权限审计
- 密级管理：人员定密（个人/按岗位批量）、业务数据定密（公文文单、附件）、密级过滤选人
- A8 方案补充：协同模板/文单密级、安全下载、安全查看
